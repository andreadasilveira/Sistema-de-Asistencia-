# Sistema-de-Asistencia-
Sistema de Asistencia (Módulo de Login) Interfaz web moderna, limpia y minimalista desarrollada con HTML5, CSS3 y JavaScript. Diseñada con una paleta de colores en tonos rosados suaves y una estructura centrada mediante Flexbox, pensada para ofrecer una experiencia de usuario agradable y responsiva en el acceso a paneles de control de asistencia.
