Sistema de Asistencia - Módulo de Inicio de Sesión
Este proyecto contiene la interfaz de usuario para el inicio de sesión de un Sistema de Asistencia, diseñada con un estilo moderno y minimalista.
🛠️ Tecnologías Utilizadas
 * HTML5: Estructura semántica del formulario de acceso.
 * CSS3: Estilos personalizados, paleta de colores y diseño centrado (Flexbox).
 * JavaScript: Lógica de validación y control de eventos (conectado mediante script.js).
🎨 Características de Diseño
 * Paleta de Colores:
   * Fondo general en tonos rosados suaves (#fce7f3).
   * Botones y detalles de error en color rosa/magenta acentuado (#d6759e).
   * Enfoque limpio con bordes oscuros en los campos de entrada al seleccionarlos.
 * Estructura:
   * Contenedor centralizado que se adapta a la pantalla (100vh).
   * Campos obligatorios (required) para el Usuario y la Contraseña.
   * Sección de mensajes de error dinámica (#error).
🚀 Cómo Ejecutar el Proyecto
 * Asegurate de tener los siguientes archivos en la misma carpeta:
   * index.html (Código principal de la vista).
   * script.js (Lógica de autenticación y comportamiento).
 * Abrí el archivo index.html directamente en cualquier navegador web moderno (Google Chrome, Firefox, Edge, etc.).
